# Hostel Gatepass Verification System

This is a Java console application, not a website or web server.

The first version includes:

- Student login and gatepass application
- Warden login and approval or rejection of requests
- In-memory data while the application is running

## Run

```bash
javac -d build src/HostelGatePassSystem.java
java -cp build HostelGatePassSystem
```

Demo logins:

- Student: `STU001` / `student123`
- Warden: `WARDEN01` / `warden123`
